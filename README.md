# AGS Project Website

Static project website for:

**Regulating Internal Alignment Flows for Robust Learning Under Spurious Correlations**  
Accepted at **ICLR 2026**

## Files

- `index.html` - complete single-file site
- `assets/paper.pdf` - paper PDF
- `assets/heatmap_ablation.png` - ablation heatmap
- `assets/figure2_alignment_densities.png` - alignment density plots
- `assets/figure3_spuriousness_scatter.png` - spuriousness vs alignment plots

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Save. GitHub will publish the site after a short build step.

## Notes

- The site uses only plain HTML, CSS, and a tiny amount of vanilla JavaScript.
- All paths are relative, so it works directly on GitHub Pages.
- You can replace the paper link, add code links, or attach a video demo later.
